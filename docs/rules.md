# 辅食引入排程规则说明书

文件编号：GC-RULE-001　　版本：v1.3　　

---

## 1 范围

本文件规定果初辅食引入排程器的排程逻辑，包括食物筛选的硬性约束、候选食物的评分方法、排程流程、输出结构、边界条件的处理方式，以及达标率指标的计算口径。

本文件是排程算法行为的唯一定义。程序实现与本文件不一致时，以本文件为准。

| 编号 | 名称 |

## 3 术语与定义

**3.1 月龄**

自 `birth_date` 至指定日期的完整月数，不进位。

计算方式：`(d.year - b.year) × 12 + (d.month - b.month)`，若 `d.day < b.day` 则减 1。

示例：出生日期 2026-01-15，指定日期 2026-07-14 为 5 月龄；2026-07-15 为 6 月龄。

**3.2 新食物**

未在该儿童历史记录中以 `passed` 状态出现、且未出现在本次已生成计划中的食物。

**3.3 观察期**

引入一种新食物后，不再安排其他新食物的连续天数。

**3.4 富铁食物**

满足下列任一条件的食物：

- `category` 为「肉类」（含畜肉、禽类、鱼类、动物内脏、动物血）；
- `iron_mg_per_100g ≥ 4.5`。

**3.5 富锌食物**

`zinc_mg_per_100g ≥ 4.5` 的食物。

**3.6 含量阈值的来源**

GB 28050—2011 规定矿物质「高」或「富含」的含量声称条件为每 100 g 中不低于 30% NRV。铁与锌的 NRV 同为 15 mg，故两者阈值同为 30% × 15 mg = 4.5 mg/100 g。见 `evidence.md` E-12。

**3.7 本工具覆盖的营养素范围**

评分函数覆盖铁与锌两项，依据见 `evidence.md` E-14：中国疾控中心 2019—2021 年全国调查的结论为「6 至 8 月龄和 9 至 11 月龄婴儿辅食铁密度和锌密度偏低」，官方点名的即为这两项。

不纳入评分的营养素及原因：

| 营养素 | 处理方式 |
|---|---|
| 钙 | 主要来源为奶类，由 `category` 的「奶类」类别覆盖判定间接管理，不单列评分维度 |
| 维生素 A | 由 `category` 的「维生素A丰富蔬果」类别覆盖判定间接管理 |
| 维生素 D | WS/T 678—2020 附录 B 的 AI/RNI 为 10 μg/d，辅食难以达成，通行做法为每日补充剂。不纳入排程逻辑，改为界面固定提示，见 6.3 |
| 蛋白质 | 中疾控调查结论为辅食蛋白质密度**偏高**，不存在需要补足的缺口 |

## 4 数据字段与取值域

### 4.1 食物类别 `category`

取值限于以下七项，不得自行扩充：

```
谷物根茎薯类  豆类坚果  奶类  肉类  蛋类  维生素A丰富蔬果  其他蔬果
```

（「维生素A丰富蔬果」不含空格，录入与程序中统一使用该写法。）

依据：WS/T 678—2020 规定的七类常见食物，标准要求「逐渐达到每天摄入七类常见食物中的四类及以上」。


「维生素A丰富」的操作判据：胡萝卜素或维生素 A 含量较高的深色蔬果，如胡萝卜、南瓜、橙肉红薯、菠菜、西兰花、芒果、木瓜。其余归入「其他蔬果」。该判据为团队设定，须在报告中说明。

### 4.2 致敏物质 `allergen_type`

取值限于以下八项，非致敏物质留空：

```
含麸质谷物  甲壳纲类动物  鱼类  蛋类  花生  大豆  乳  坚果
```

依据：GB 7718—2025 规定的八类致敏物质。该标准将 GB 7718—2011 中的推荐性标示改为强制性标示。


`is_allergen` 可由 `allergen_type` 是否为空推出。两列不一致时以 `allergen_type` 为准。

### 4.3 形态阶段 `texture_stage`

| 取值 | 适用月龄 | 性状 | 判据 |
|---|---|---|---|
| 1 | 6 | 细腻泥糊状 | 可用舌头压碎，如软豆腐状 |
| 2 | 7～8 | 碎末状 | 可用舌头压碎 |
| 3 | 9～11 | 碎块状、可手抓的指状食物 | 可用牙床压碎，如香蕉状 |
| 4 | ≥12 | 块状、指状、小块软饭 | 可用牙床咀嚼，如肉丸子状 |

依据：WS/T 678—2020 规定三个阶段（6～8 月龄、9～12 月龄、1～2 岁）。本文件将标准中 6～8 月龄阶段内部的「从泥糊状逐渐到碎末状」拆分为阶段 1 与阶段 2，其余边界与标准一致。阶段 2 为团队细化，须在报告中说明。

### 4.4 营养素来源 `nutrient_source`

| 取值 | 含义 |
|---|---|
| `animal` | 动物性来源 |
| `plant` | 植物性来源 |
| 空 | 铁与锌含量均可忽略 |

设置该字段的原因：部分植物性食物（如黑木耳、紫菜、芝麻）的铁含量数值高于多数肉类，但其铁为非血红素铁，吸收率显著低于血红素铁；锌的吸收同样受植物性食物中植酸的影响。若评分仅依据含量数值，此类食物将排在肉类之前。评分时对植物性来源的铁与锌按 0.5 折算，见 5.2.1。

该字段同时服务于铁与锌两项评分，故命名为 `nutrient_source`。折算系数 0.5 为团队设定，须在报告中说明。

### 4.5 锌含量 `zinc_mg_per_100g`

每 100 克食物的锌含量，单位毫克。数据来源与 `iron_mg_per_100g` 相同（中国食物成分表），录入时同条记录一并填写。

### 4.6 已知过敏原 `known_allergens`

该字段存储致敏物质类别，取值限于 4.2 的八类，非食物编号。排除范围见 5.1 的 C5。

家长在填资料页勾选的是致敏物质类别，不逐一勾选食材。


## 5 排程规则

### 5.1 硬性约束

以下判定均针对「候选食物 f、儿童 child、拟安排日期 d」。任一条不满足即排除。

**C0 推荐开关**

```
f.auto_recommend == 1
```

`auto_recommend` 为食物库新增字段，取值 0 或 1。取 0 时该食物无论月龄、形态、当季与否均不进入候选池。

依据：部分食物因「品种未明确、致敏类别超出八类契约、饮品不参与固体质地筛选」等原因，不能由程序自动推荐给真实家庭。这类食物仅以 `min_month=12` 作占位以通过导入契约，但月龄下限无法拦截 ≥12 月龄的儿童，故必须由 `auto_recommend=0` 在 C2 之前显式排除。当前 `auto_recommend=0` 的食物为：金枪鱼（68）、扇贝（69）、无糖豆浆（73）、芝麻（81）。

**C1 新食物观察期**

安排一种新食物后，N 天内不再安排其他新食物。

```
if last_new_food_date is not None and (d - last_new_food_date).days < N:
    当天不安排新食物
```

参数：N = 4（取值区间 3～5 的中值）。

依据：WS/T 678—2020「每引入一种新的食物应适应 3d～5d，观察是否出现呕吐、腹泻、皮疹等不良反应」；中国居民膳食指南（2022）「一次只添加一种新食物，隔 3 至 5 天之后再添加另一种」。

注：该约束为全局闸门，不针对单一食物。观察期内可继续摄入已通过的食物。

**C2 月龄下限**

```
月龄(child, d) >= f.min_month
```

依据：WS/T 678—2020「纯母乳喂养到 6 月龄，且在孩子健康时添加辅食」。各食材的具体起始月龄由录入时的 `source` 列标明。

约束：食物库中 `min_month` 的最小值不得小于 6，由录入校验脚本检查。

**C3 不良反应冷却期**

若历史记录中存在 `(food_id = f.id, status = 'reaction', date = r)` 且 `(d - r).days < D`，排除 f。

参数：D = 90。

性质：产品边界设定，非标准条款。国家标准与膳食指南未规定出现不良反应后的复试时机，该判断属医学判断，不在本工具的功能范围内。D 取 90 天的效果是：出现反应的食物在计划期内不再被安排。在 6 周计划期内，D 取 45 或 90 的实际效果一致。

界面文案不得给出复试时机，应表述为：「已从后续安排中移除。是否、何时可以再尝试，请咨询儿科医生或儿保医生。」

**C4 形态阶段上限**

```
f.texture_stage <= 允许阶段(月龄(child, d))
```

允许阶段：月龄 6 → 1；7～8 → 2；9～11 → 3；≥12 → 4。

依据：WS/T 678—2020，见 4.3。

**C5 已知过敏排除**

```
f.allergen_type 非空 且 f.allergen_type in child.known_allergens
```

`child.known_allergens` 存储致敏物质类别（如「蛋类」），不存食物编号。按类别排除后，同类其他食物（如鹌鹑蛋）也不会进入候选。

依据：GB 7718—2025 按类别管理致敏物质。

配套要求：填资料页应提供八类致敏物质的勾选项，而非逐一勾选食材。

**C6 已摄入食物排除**

```
not 吃过(child, f)
```

`status = 'refused'` 不计入「吃过」，该食物可再次安排。同一食物累计 `refused` 达到 `MAX_REFUSE` 次后不再安排。

参数：MAX_REFUSE = 3（团队设定）。

### 5.2 评分函数

```
score(f, child, d) = 0.25 · iron(f)
                   + 0.15 · zinc(f)
                   + 0.30 · gap(f, child, d)
                   + 0.10 · allergen_early(f, child, d)
                   + 0.20 · season(f, d)
```

五项子分取值均归一化至 [0, 1]，总分取值域 [0, 1]。

**5.2.1 iron 与 zinc 营养素项**

```
factor = 1.0   若 f.nutrient_source == 'animal'
         0.5   若 f.nutrient_source == 'plant' 或为空

iron = min(f.iron_mg_per_100g / 4.5, 1.0) × factor
zinc = min(f.zinc_mg_per_100g / 4.5, 1.0) × factor
```

阈值 4.5 的来源见 3.6。折算系数 0.5 为团队设定，依据为非血红素铁的吸收率低于血红素铁、植物性食物中的植酸抑制锌吸收，须在报告中说明其为团队设定。

铁的权重高于锌，依据：中疾控 2019—2021 年调查中，6～8 月龄婴儿辅食来源的铁为 1.3 mg（该月龄 RNI 为 10 mg），锌为 0.7 mg（RNI 3.5 mg）；且母乳仅能提供约 5% 的铁需要量，缺铁性贫血对认知发育的影响有国家卫健委的明确表述。

**5.2.2 gap 类别缺口项**

```
recent = 最近 7 天（含历史记录与本次已生成计划）中出现过的 category 集合
gap    = 1.0  若 f.category 不在 recent 中
         0.0  否则
```

依据：WS/T 678—2020「逐渐达到每天摄入七类常见食物中的四类及以上」。

**5.2.3 allergen_early 致敏物质引入项**

```
allergen_early = 1.0  若 f.allergen_type 非空 且 月龄(child, d) < 12
                 0.0  否则
```

依据：中国营养学会《中国婴幼儿喂养指南（2022）》7～24 月龄部分准则二「不盲目回避易过敏食物，比如鸡蛋、小麦、鱼、坚果等」「1 岁内适时引入各种食物达到食物多样化，能帮助婴儿达到营养均衡，也能减少食物过敏风险」。

**5.2.4 season 当季项**

```
season = 1.0  若 d.month 在 f.season_months 中
         0.0  否则
```

`season_months` 为空或填 `1-12` 时视为全年，恒取 1.0。该项为团队设定，依据为成本与新鲜度。

**5.2.5 排序规则**

1. 评分四舍五入至小数点后 6 位后比较；
2. 评分高者优先；
3. 评分相同时，`food_id` 小者优先。

排序结果须为确定性的。同一输入的多次调用必须返回相同结果，不得使用随机数或依赖字典遍历顺序。

**5.2.6 权重来源**

| 项 | 权重 | 依据性质 |
|---|---|---|
| iron | 0.25 | 国家监测数据与卫健委公开表述，见 `evidence.md` E-03、E-04、E-06、E-14 |
| zinc | 0.15 | 中疾控点名辅食锌密度偏低，见 `evidence.md` E-03、E-14 |
| gap | 0.30 | WS/T 678—2020 与全国达标率数据，见 `evidence.md` E-01、E-07 |
| allergen_early | 0.10 | 中国婴幼儿喂养指南（2022），见 `evidence.md` E-11 |
| season | 0.20 | 团队设定 |

铁与锌合计 0.40，与上一版本中 iron 单项的权重一致，两者的相对比例为 5:3。

### 5.3 排程流程

```python
def generate_schedule(child_id, weeks=6, today=None):
    child   = load_child(child_id)
    foods   = load_foods()
    history = load_history(child_id)

    start = today or date.today()
    end   = start + timedelta(days=weeks * 7)

    if weeks <= 0 or 月龄(child, start) < 6:
        return []

    last_new = max((h["date"] for h in history
                    if h["status"] in ("passed", "planned", "reaction")),
                   default=None)

    plan = []
    d = start
    while d < end:
        if last_new is not None and (d - last_new).days < N_OBSERVE:
            d += timedelta(days=1)
            continue

        cands = [f for f in foods
                 if f.auto_recommend
                 and f.source.strip()
                 and pass_c2(f, child, d) and pass_c3(f, child, d)
                 and pass_c4(f, child, d) and pass_c5(f, child)
                 and pass_c6(f, child, history, plan)]

        if not cands:
            record_blocked(d)
            d += timedelta(days=1)
            continue

        best = min(cands, key=lambda f: (-round(score(f, child, d), 6), f.id))

        plan.append({
            "date":         d,
            "food_id":      best.id,
            "food_name":    best.name,
            "texture":      best.texture_stage,
            "texture_desc": TEXTURE_DESC[best.texture_stage],
            "reason":       build_reason(best, child, d),
            "source":       best.source,
        })
        last_new = d
        d += timedelta(days=1)

    return plan
```

### 5.4 重排流程

`report_reaction(child_id, food_id, date)` 的处理顺序：

1. 写入一条 `status = 'reaction'` 的记录；
2. 丢弃该日期之后的全部未执行计划；
3. 以 `date + N_OBSERVE` 为起点重新调用 `generate_schedule`；
4. 返回新计划。

重排为整段重算，不在原计划上做局部修改。重算后 C3 自动排除出现反应的食物，类别缺口自动重新计算。

## 6 输出规格

每条计划条目包含且仅包含以下七个字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `date` | `datetime.date` | 安排日期，非字符串 |
| `food_id` | `int` | 食物编号 |
| `food_name` | `str` | 食物名称 |
| `texture` | `int` | 形态阶段 1～4 |
| `texture_desc` | `str` | 形态阶段的文字描述 |
| `reason` | `str` | 推荐理由，生成规则见 6.1 |
| `source` | `str` | 依据出处 |

### 6.1 `reason` 生成规则

由评分中贡献最大的一项决定文案模板：

| 主导项 | 文案模板 |
|---|---|
| iron | 本周已 {X} 天未安排富铁食物。6 个月后母乳仅能提供约 5% 的铁需要量，其余需从辅食补充。 |
| zinc | 本周已 {X} 天未安排富锌食物。全国调查显示 6～11 月龄婴儿辅食的锌密度偏低。 |
| gap | 七类食物中的「{类别}」本周尚未覆盖。国家标准要求每天摄入七类中的四类及以上。 |
| season | {月份} 月正当季。 |
| allergen_early | 此为八大致敏物质之一，建议在 12 月龄前引入并观察。 |

`source` 字段填写该食物 `foods.csv` 中的 `source` 列，并附触发该建议的规则编号，例如 `WS/T 678—2020（C1、评分-gap）`。

### 6.2 文案限制

`reason` 及不良反应提示文案中不得出现判断性表述，包括但不限于「过敏」「可能是」「应该是」「建议服用」「不用担心」「没关系」「确诊」「治疗」。

不良反应发生时的唯一提示文案：「停止添加这种食物；记录时间和具体表现；如果反应严重，请及时就医。」

首页固定文案：「本工具依据公开发布的国家标准与膳食指南整理，未经专业机构复核，不能替代儿科医生或注册营养师的建议。」

### 6.3 维生素 D 提示

首页固定提示：「维生素 D 的推荐摄入量为每日 10 μg，辅食难以达成，通常需要额外补充。具体剂量请咨询儿科医生或儿保医生。」

该提示为静态文案，不参与排程逻辑，不随儿童数据变化。依据：WS/T 678—2020 附录 B 规定 0.5～1 岁与 1～2 岁的维生素 D 均为 10 μg/d，见 `evidence.md` E-15。

提示中不得出现具体补充剂品牌、剂型或服用方法。

## 7 边界条件

| 条件 | 处理方式 |
|---|---|
| 月龄 < 6 | 返回空列表，界面提示「满 6 月龄后再开始」 |
| `weeks` ≤ 0 | 返回空列表 |
| 某日所有食物均被排除 | 跳过该日，继续后排，不抛异常、不填充占位条目 |
| 计划期内跨越月龄边界 | 每日按当日月龄重新判定 C2、C4，不使用起始日月龄 |
| `season_months` 为空 | 视为全年，`season = 1.0` |
| `iron_mg_per_100g` 为空 | 视为 0，`iron = 0` |
| `source` 为空 | 该食物不进入候选池，导入时报警 |
| 同日既有历史记录又需排新食物 | 历史优先，该日不排新食物 |

## 8 参数汇总

## 9 达标率计算

### 9.1 口径

采用 WHO 2008 版 IYCF 指标口径，与 2013 年全国基线可比，且与 WS/T 678—2020 的「七类中四类及以上」一致。依据见 `evidence.md` E-01、E-02、E-07。

不采用 WHO 2021 版（八类中不少于五类，母乳单列为一类）。两版口径的计算结果不可直接比较。

### 9.2 数据来源

计算输入为每日膳食类别记录表 `daily_intake`，非排程记录表 `records`。排程记录仅含本工具安排的新食物，不含儿童当日的全部膳食。

`daily_intake` 字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `child_id` | `str` | 儿童编号 |
| `date` | `datetime.date` | 记录日期 |
| `categories` | `list[str]` | 当日摄入的食物类别，取值限于 4.1 的七类 |
| `meal_count` | `int` | 当日辅食餐次，不含奶类喂养 |
| `is_breastfed` | `int` | 是否仍在母乳喂养，1 或 0 |
| `milk_feeds` | `int` | 当日奶类喂养次数 |

实验组与对照组均需采集该表。

### 9.3 计算规则

以「儿童-日」为计算单位。

**最低膳食多样性 MDD**

```
MDD(child, d) = len(set(categories)) >= 4
```

**最低进食频次 MMF**

```
若 is_breastfed == 1 且 6 <= 月龄 <= 8：   MMF = meal_count >= 2
若 is_breastfed == 1 且 9 <= 月龄 <= 23：  MMF = meal_count >= 3
若 is_breastfed == 0：                     MMF = (meal_count + milk_feeds) >= 4 且 meal_count >= 1
```

**最低可接受膳食 MAD**

```
若 is_breastfed == 1：MAD = MDD 且 MMF
若 is_breastfed == 0：MAD = MDD 且 MMF 且 milk_feeds >= 2
```

**富铁食物周摄入频次**

```
某周内 categories 含「肉类」的天数
```

该指标无全国基线，仅用于实验组与对照组的组间比较。



### 9.4 结论边界

三周观察期、10～15 户样本不支持营养状况改善的统计推断。可报告范围限于达标率、指标频次与使用行为。
