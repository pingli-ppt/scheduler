# 排程算法验收用例

更新日期：2026-09-26

| 编号 | 场景 | 预期结果 |
|---|---|---|
| T01 | 起始日尚未满 6 月龄 | 返回空列表 |
| T02 | `weeks` 为 0 或负数 | 返回空列表 |
| T03 | 出生日期为 1 月 15 日，检查 7 月 14/15 日 | 分别为 5/6 月龄 |
| T04 | 连续生成多种新食物 | 相邻安排至少相隔 4 天 |
| T05 | 计划中跨过完整月龄生日 | 每天重新计算月龄和形态上限 |
| T06 | 儿童已知过敏类别为蛋类 | 所有 `allergen_type=蛋类` 的食物均排除 |
| T07 | 某食物发生反应后第 89/90 天 | 第 89 天排除，第 90 天允许重新候选 |
| T08 | 同一种食物拒食 1～2/3 次 | 前者仍可候选，第三次后排除 |
| T09 | 食物 `source` 为空 | 不进入候选池 |
| T10 | 所有食物均不合格 | 跳过日期，不生成占位条目 |
| T11 | 两种候选的六位小数评分相同 | `food_id` 较小者优先 |
| T12 | 植物性来源铁、锌达到 4.5 mg/100g | 对应子分均按 0.5 折算 |
| T13 | 同日已经存在历史记录 | 历史优先，当天不安排新食物 |
| T14 | 输出一条计划 | 恰好包含规定的 7 个字段，日期为 `date` |
| T15 | 上报不良反应 | 原子写入反应并删除该日之后的未来计划 |
| T16 | 完成反应处理 | 从反应日期加 4 天开始重新生成六周计划 |

自动化实现位于 `tests/test_algorithm.py` 与 `tests/test_repository.py`。
