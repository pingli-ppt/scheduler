# 果初 · 辅食引入排程器

果初是一个面向 6–12 月龄婴幼儿家庭的辅食引入排程原型。项目将月龄、食物性状、观察期、已知过敏、食物多样性与营养优先级等规则转化为可执行的计划；当家长记录不良反应后，系统能够避开相关食物并重新排程。

> 本项目用于学生课题研究与原型验证，不替代医生、注册营养师或其他专业医疗建议。

## 目标

- 根据儿童档案、食物库和历史记录生成未来 4–6 周的引入计划。
- 为每项推荐提供可解释的理由和规则出处。
- 支持通过、反应、拒食等结果记录，并在必要时自动重排。
- 以轻量 H5 完成家庭内测，验证排程采纳率、回访率和引入种类等指标。

## 技术栈

- Python
- FastAPI
- SQLite
- 原生 HTML、CSS 与 JavaScript

项目优先完成可运行的命令行排程器，再建设 API 和前端页面。

## 仓库结构

```text
guochu/
├── docs/       数据契约、规则、测试用例、接口与复核记录
├── data/       食物库、数据读取与校验
├── algo/       约束、打分、排程与重排算法
├── api/        FastAPI 接口
├── web/        H5 页面与静态资源
└── analysis/   内测行为与成本分析
```

## 核心里程碑

1. 固化数据字段、规则编号、输入输出契约。
2. 建立首批食物数据并完成数据校验。
3. 跑通命令行版约束、打分和 4–6 周排程。
4. 完成反应上报后的回避与重排。
5. 接入 API 与 H5，部署可演示版本。
6. 进行小规模内测并整理验证报告。

## 协作约定

- 每位成员使用自己的 Git 账号提交，提交内容保持单一、说明清晰。
- 数据契约确定后，不单方面修改字段或跨模块返回结构。
- 规则、营养数据和提示文案注明公开出处及复核状态。
- 不提交真实姓名、联系方式、儿童身份信息、密钥、`.env`、本地数据库或内测原始隐私数据。
- 真实配置以 `.env.example` 提供模板，敏感值只保存在本地环境。
